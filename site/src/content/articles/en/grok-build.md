## Conclusion

Use Grok Build as the shipping-oriented agent when your acceptance criteria and demo path are already written down.

## Prerequisites

- Access to current xAI / Grok Build docs and product surface
- A landing or demo target you can actually open

## Steps

1. Open the current xAI docs and confirm the Build workflow you intend to use.
2. Feed a short ship brief: user, problem, demo path, and non-goals.
3. Keep marketing claims separate from verified product behavior.
4. After a build, run a human smoke test of the public path (home, pricing, signup/contact).
